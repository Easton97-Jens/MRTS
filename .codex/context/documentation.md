# MRTS Documentation Policy Delta

MRTS reader-facing documentation is versioned repository content and follows the repository's existing language/layout conventions. Do not invent a Parent/Framework bilingual requirement where MRTS does not define one.

Keep command examples, Python-version statements, generator paths, dependency requirements, and governance instructions aligned with the current implementation and CI.

Local `.codex` control files are execution/governance configuration, not a substitute for product documentation when a versioned behavior change requires documentation.
