# MRTS Definition of Done Delta

An MRTS task is complete only when the original request and acceptance criteria are reconciled and all authorized work is truthfully accounted for.

Verify as applicable:

- correct MRTS repository/branch/base SHA;
- action classes were not exceeded;
- required focused tests/governance checks were actually run;
- generated/runtime output stayed in authorized locations;
- no Parent/Framework files or Gitlinks changed by implication;
- Git/remote/PR facts match observed state;
- task-owned processes and temporary resources are reconciled;
- cleanup manifest/lifecycle is consistent;
- remaining risks, blockers, skipped checks, and evidence limits are reported.

A completed analysis may contain failed product tests. Do not report delivery or merge that did not occur.
